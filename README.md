# MovieLog 9주차 프론트엔드

8주차 MovieLog에서 이어서 즐겨찾기, 영화 검색, 더 보기 페이지네이션을 구현했다. 로그인·회원가입·회원 정보·평점·즐겨찾기는 워크북의 `/v8` API를 사용한다. 영화 목록과 검색은 TMDB API를 사용한다.

## 실행

프로젝트 폴더에서 아래 명령어로 환경 파일을 준비한다.

```bash
cp -n .env.example .env
```

`.env`의 `TMDB_ACCESS_TOKEN`에 기존 TMDB API Read Access Token을 입력한다. `MOVIELOG_API_BASE_URL`의 기본값은 워크북 서버다. `.env`는 Git 추적에서 제외된다.

```bash
flutter pub get
flutter analyze
flutter test
open -a Simulator
flutter run -d ios
```

## 즐겨찾기 API

| 동작 | 요청 | 성공 응답 |
| --- | --- | --- |
| 등록 | `POST /v8/favorites`, 바디 `{"movieId": 550}` | 201, `result`에 즐겨찾기 객체 |
| 내 목록 | `GET /v8/favorites` | 200, `result`에 배열 |
| 등록 여부 확인 | `GET /v8/favorites/{movieId}` | 200, `result.isFavorite` |
| 해제 | `DELETE /v8/favorites/{movieId}` | 200, `result: null` |

`movieId`는 TMDB 영화 ID다. 내 목록의 계정은 서버가 JWT로 확인한다. 상세에서 해제하고 뒤로 가면 목록을 다시 조회한다. 제목과 포스터는 TMDB에서 최대 다섯 건씩 조회하며, 한 건이 실패하면 해당 카드에서 다시 조회할 수 있다. [워크북 Swagger](https://workbook.devnoco.com/docs/v8)

## 스터디 인증 문법

| 문법 | 설명 |
| --- | --- |
| `Map` | 키와 값을 짝지어 저장하며, 즐겨찾기의 `movieId`로 TMDB 영화 정보를 찾을 수 있다. |
| `Future.wait` | 여러 비동기 작업이 완료되기를 기다리고 입력 순서대로 결과를 반환한다. |
| `record` | 여러 값을 묶어 전달하는 타입이며, 인증 브리지에서 세션 버전과 이메일을 한 값으로 비교한다. |
| `interface` | 구현 클래스가 제공할 메서드의 계약을 정의하며, 같은 계약을 갖는 장르 설정 저장소를 테스트에서 교체할 수 있다. |
| `mixin` | 여러 클래스에 공통 동작을 추가하며, `SafeNotify`는 화면 종료 후 상태 변경 알림을 방지한다. |
| `ValueKey` | 키로 위젯의 동일성을 판정하며, 계정이나 세션이 바뀌면 새 즐겨찾기 ViewModel을 만든다. |
| 요청 `generation` | 요청 조건이 바뀔 때 번호를 올리고 현재 번호와 일치하는 응답만 화면에 반영한다. |

## 검증 기록

Flutter 3.47.4에서 정적 분석을 마쳤고 자동 테스트 80개가 통과했다.

| 항목 | 확인 내용 |
| --- | --- |
| 상세와 내 즐겨찾기 | 위젯 테스트에서 상세 등록·해제, 북마크·Snackbar 변경, 복귀 후 제거, 다른 계정의 목록 표시를 확인했다. |
| 일부 영화 정보 실패 | 한 건이 실패한 목록을 유지하고 재시도 시 해당 영화 ID만 다시 조회하는 동작을 테스트했다. |
| 더 보기와 검색 | 첫 페이지 요청, 중복 제거, 다음 페이지 실패 뒤 같은 페이지 재요청, 검색 제출 시점, 상세 이동, 늦은 응답 무시 및 TMDB 500페이지 상한을 테스트했다. |
| 계정과 인증 오류 | 가짜 응답으로 `FAVORITE409_1`·`FAVORITE404_1` 재조회와 현재 세션만 만료하는 동작을 확인했다. |
| 제출용 영상과 캡처 | 본인 계정과 iOS 시뮬레이터에서 실제 등록·해제, 빈 목록·오류, 더 보기 실패 후 재시도, 검색 결과·빈 결과·오류, 계정 전환을 확인해 촬영한다. 디버그 콘솔의 `[MovieLog]` 로그에는 즐겨찾기 요청 경로, HTTP 상태, 오류 코드만 표시된다. |

## 트러블슈팅

앱 재시작 시 인증 복원 코드가 저장소의 기존 토큰을 테스트용 문자열로 덮어썼다. 테스트용 쓰기를 제거하고 저장된 토큰으로 내 정보를 조회하도록 수정했다. 복원 조회에 실패하면 기존 토큰을 보존하고, 만료 응답을 받은 경우에만 정리하는 동작을 테스트했다.
