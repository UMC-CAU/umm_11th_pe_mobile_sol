# MovieLog — 7주차 프론트엔드

6주차 MovieLog에 회원가입과 평점 등록·조회·수정·삭제를 연결한 Flutter 프로젝트입니다. 7주차 프론트 워크북의 MovieLog **v6** API를 사용합니다.

## 실행하기

1. Flutter SDK를 준비하고 프로젝트 폴더에서 패키지를 설치합니다.

   ```bash
   flutter pub get
   ```

2. 환경변수 파일을 만듭니다.

   ```bash
   cp .env.example .env
   ```

3. `.env`의 `TMDB_ACCESS_TOKEN`에 본인의 TMDB Read Access Token을 넣습니다. `MOVIELOG_API_BASE_URL`은 v6 워크북 서버의 기본 주소가 설정되어 있으며, 별도 서버를 사용할 때에는 해당 v6 계약을 제공하는 주소로 바꿉니다. 토큰이나 비밀번호가 담긴 `.env`는 Git에 올리지 않습니다.
4. iOS 시뮬레이터 또는 Android 에뮬레이터를 실행하고 앱을 시작합니다.

   ```bash
   flutter run
   ```

   예를 들어 Mac에서 iOS 시뮬레이터를 열려면 `open -a Simulator`를 실행한 다음 `flutter devices`로 확인합니다.

## 사용 흐름

1. 시작 화면에서 회원가입을 열고 닉네임과 이메일 중복을 각각 확인합니다. 비밀번호는 8자 이상이며 영문 대문자·소문자·숫자·`!@#$%^&*` 중 특수문자가 각각 필요합니다.
2. 가입에 성공하면 서버가 반환한 `memberId`를 메모리의 `LearningMemberSession`에 저장하고 영화 목록으로 이동합니다.
3. 영화를 골라 상세 화면에서 1~5점 정수 별점과 선택 코멘트를 저장합니다. 요청의 `movieId`는 TMDB 영화 ID입니다.
4. 마이페이지 → **내가 등록한 평점**에서 해당 회원의 기록을 확인하고 수정 또는 삭제합니다. 편집 메뉴의 다중 선택·삭제도 사용할 수 있습니다.

학습용 회원 ID는 앱을 종료하면 사라집니다. 회원 ID는 로그인 인증이 아니며 앱을 재시작하면 이번 실습 흐름에서는 학습용 회원가입이 다시 필요합니다. 영화 상세와 내 평점에서 회원 ID가 없을 때 가입을 안내합니다.

## API 계약

| 기능 | 요청 | 성공 응답 |
| --- | --- | --- |
| 닉네임·이메일 확인 | `GET /v6/members/nickname/{nickname}`, `GET /v6/members/email/{email}` | 200, 직접 객체 |
| 회원가입 | `POST /v6/members` | 201, 공통 응답의 `result.memberId` |
| 평점 조회 | `GET /v6/members/{memberId}/ratings` | 200, 직접 배열 |
| 평점 등록 | `POST /v6/members/{memberId}/ratings` | 201, 공통 응답 |
| 평점 수정 | `PATCH /v6/members/{memberId}/ratings/{ratingId}` | 200, 공통 응답 |
| 평점 삭제 | `DELETE /v6/members/{memberId}/ratings/{ratingId}` | 204, 본문 없음 |

평점 쓰기 성공 후 재조회가 실패하면 저장 실패와 구분해 표시하며, 재시도는 조회만 수행합니다. 400·403·404·409에서는 서버 메시지를 표시하고, 403·404에서 목록을 다시 조회합니다. TMDB와 MovieLog는 서로 다른 클라이언트를 사용합니다.

보내준 백엔드 JWT 워크북의 `/auth/login`, `/ratings`, `/members/me`는 다른 계약입니다. 이 앱은 프론트 7주차 워크북의 `/v6/members/{memberId}/ratings`를 사용하므로 JWT 백엔드에 그대로 연결해 검증할 수 없습니다.

## 검증

```bash
flutter analyze
flutter test
```

코드 작성 환경에서는 정적 분석과 자동 테스트를 수행했습니다. 테스트는 가짜 응답을 사용합니다. 실제 워크북 서버와 iOS/Android 기기의 수동 검증, 화면 캡처와 제출용 영상은 별도로 진행해야 합니다.

### 제출 전 수동 확인

- 닉네임·이메일 중복 확인 후 입력을 바꾸면 확인 결과가 지워지는지 확인합니다.
- 본인 테스트 계정으로 회원가입하고 성공 결과와 최종 409 응답을 확인합니다. 비밀번호는 캡처하지 않습니다.
- 영화 상세에서 평점과 코멘트를 등록하고, 마이페이지에서 조회·수정·삭제 및 마지막 항목 삭제 후 빈 화면을 확인합니다.
- 저장 실패 시 입력이 남는지, 저장 후 목록 조회 실패 시 조회만 재시도하는지 확인합니다.
- 편집 모드의 다중 삭제와 일부 실패, 요청 중 이탈 방지를 확인합니다.
- 제출할 화면·영상과 PR을 준비합니다.
